# WILDERNESS: Survival

Небольшая браузерная 3D survival-игра от первого лица. Работает на GitHub Pages.

## Запуск локально
Из-за ES-модулей браузеру нужен локальный сервер. Самый простой вариант:
1. Открой папку в VS Code.
2. Установи расширение **Live Server**.
3. Нажми правой кнопкой по `index.html` → **Open with Live Server**.

Либо запусти в папке проекта:
```bash
python -m http.server 8000
```
И открой http://localhost:8000

## Публикация на GitHub Pages
1. Создай новый публичный репозиторий на GitHub.
2. Загрузи `index.html`, `style.css`, `game.js`, `README.md` в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми **Save**.
6. Через минуту открой адрес вида `https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Управление
- WASD — ходьба
- Shift — бег
- Space — прыжок
- Мышь — обзор
- ЛКМ — ударить / добыть ресурс
- E — взаимодействовать с объектом
- 1 / 2 / 3 — выбрать слот
- ПКМ — использовать выбранный предмет
- Esc — пауза

## Важно
- Для 3D используется Three.js с CDN, поэтому при первом запуске нужен интернет.
- Музыка генерируется кодом в браузере: это оригинальная спокойная ambient-подложка, а не аудиозапись из Minecraft.
- Сохранение использует `localStorage` этого браузера и устройства.
- Это стартовая игровая версия: её можно расширять новыми биомами, крафтом, мобами и предметами.
